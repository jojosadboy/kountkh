YOUTH AND BUSINESS IMMERSION 2026 WEBSITE

Files:
- index.html: countdown homepage
- agenda.html: four-day interactive agenda
- styles.css: website styling and responsive layout
- script.js: event settings, live countdown, and agenda day data
- assets/logo.png: event logo shown in the header
- assets/favicon.png: browser tab icon made from the event logo
- assets/event-banner.jpg: optional wide hero banner image

Event settings:
- Event dates: October 29 to November 1, 2026
- Location: Siem Reap, Cambodia
- Countdown target: October 29, 2026 at 5:30 AM Cambodia time, the scheduled bus departure to Siem Reap.
- Agenda: all four days and the sessions provided.

To customize the logo, replace assets/logo.png and assets/favicon.png with your new logo files.
To customize the banner, add your image as assets/event-banner.jpg.
To change the countdown or agenda, edit EVENT_CONFIG at the top of script.js.

IMPORTANT: Upload/replace the entire project folder, not only index.html. If using a browser cache, press Ctrl+F5 after replacing the files.
